# JetBrains' ring benchmarks: kc vs kotlinc

The "ring" micro-benchmarks of Kotlin's performance suite
([kotlin-native/performance/ring](https://github.com/JetBrains/kotlin/tree/c2b1102ad6118f0767e1b576cbd9f35e5b2565da/kotlin-native/performance/ring)),
compiled by each compiler and run under JMH on the same JVM. Generated by
`bench/ring.sh`.

- Machine: Linux x86_64, 4 CPUs
- openjdk version "21.0.12.1" 2026-08-18
- info: kotlinc-jvm 2.4.21 (JRE 21.0.12.1+1-1-24.04.4-Ubuntu)
- JMH 1.37, average time: 1 fork(s) per build, 5 warmup and 5 measured iterations of 200ms; JVM options: -Xms1g -Xmx1g

200 benchmarks. Time per operation, so lower is better; a ratio above 1 means kc's code is slower.

- **Geometric mean of kc / kotlinc: 1.24**
- kc's code is more than 10% slower on 39, more than 10% faster on 12, and within 10% on 149.
